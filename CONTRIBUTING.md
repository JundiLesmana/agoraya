# Contributing to Agoraya.

1. Read `AGENTS.md`, `docs/ai/INDEX.md`, and relevant ADRs.
2. Work from latest `origin/development` on one issue branch. Preserve uncommitted work.
3. Use Conventional Commits and open a PR to `development`.
4. Include acceptance criteria, exact test commands/results, security/data effects, and screenshots for UI changes.
5. Do not self-approve. Address review requests; rerun checks after revisions.
6. Release changes to protected `main` only through a reviewed release PR from `development`.

AI tools are contributors, not owners. Human reviewers are accountable for product, security, data, and deployment decisions.
